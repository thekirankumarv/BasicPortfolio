# Basic Portfolio

Personal portfolio website of **Kiran Kumar V**, Full Stack Developer.

**Live site:** https://kirankumarv.netlify.app/

## Features

- Responsive single-page layout with sticky navbar and mobile menu
- Sections: Home, About, Services, Portfolio, Contact
- Typing animation with [Typed.js](https://github.com/mattboldt/typed.js)
- Scroll animations with [ScrollReveal](https://scrollrevealjs.org/)
- Icons from [Boxicons](https://boxicons.com/)
- Project showcase linking to GitHub repositories
- Contact form via `mailto:`

## Tech Stack

HTML, CSS, JavaScript (no build step)

## Project Structure

```
.
├── index.html
├── css/style.css
├── js/script.js
├── images/
└── audio/
```

## Run Locally

```bash
git clone https://github.com/thekirankumarv/BasicPortfolio.git
cd BasicPortfolio
open index.html   # or serve: python3 -m http.server 8000
```

## Deployment

Hosted on Netlify. Deploy by connecting the repo to Netlify with no build command and the publish directory set to the repo root.
